# Smeagol Control v0.1

LoRa通信試験のための最小受信モニターです。Python 3.10以上とブラウザで動きます。
提供された **JRC2SR26 Leg1.kml** を同梱しています。

## 起動

このフォルダーで次を実行してください。

```console
python server.py
```

ブラウザで http://127.0.0.1:8765 を開きます。Windowsで `python` が使えない場合は、Pythonを導入するか `py server.py` を使ってください。
通常起動には追加のPythonパッケージは不要です。終了は Ctrl+C。

1. KMLのコース・地点が表示されます。背景地図は右上のチェックで有効にできます。
2. 「疑似走行を開始」で、KML中の最初のSSの座標列を毎秒1点ずつ移動します。速度30は表示テスト値であり、座標間距離からの計算値ではありません。
3. 車両番号をクリックすると詳細を表示。一覧の選択で車両へ地図を移動します。
4. 手動入力に実パケットを貼り付けて「受信させる」を押すと更新されます。

サンプルパケットの位置はKMLのコースから離れています。受信後に一覧のV001を選ぶとサンプル位置へ移動します。コース上の動作確認には疑似走行を使ってください。

## 受信経路

`HTTP / serial → Receiver.receive() → parse_packet() → JSONLログ + 最新車両状態 → 500ms間隔でWeb画面更新`

HTTP入力は `POST /api/packet`、JSON本文は次の形式です。

```json
{"packet":"V001,35.245174,138.918307,1.0,8,0.00,0.00,0.00,0.00,0.0,OK"}
```

ブラウザ表示の更新間隔と無線パケット受信間隔は別です。ログ時刻はPythonが完全な1行を受信した管制PCのUTC時刻です。

## パケットの扱い

|項目|解釈|
|---|---|
|1|Vehicle ID。英数字・ハイフン・アンダースコア、24文字以内|
|2–3|緯度・経度（度）|
|4|速度。単位は未確認のため生値表示|
|5|衛星数|
|6–10|センサー値1〜5。軸・意味・単位は未確認|
|11|OK または SOS|

10秒以上未受信の車両は点線枠になります。これは経過時間の目安であり、停止・事故・パケット欠落の判定ではありません。
RSSIはパケットに含まれていないため未取得です。送信連番と送信時刻もないため、欠落率や片道遅延は計算しません。受信回数には重複パケットも含みます。

## ES920LR3 USBへの接続準備

```console
python -m pip install -r requirements-serial.txt
python server.py --serial COM3 --baud 115200
```

COM番号とbaudは実機設定に合わせて変更してください。115200は仮の初期値で、実機確認済み設定ではありません。
Linuxなら `--serial /dev/ttyUSB0` を指定します。
現在のアダプターは **改行区切りのCSVペイロード** を前提にしています。タイムアウトで分割された行は保持して次の読み取りと結合し、切断時は再接続を試みます。
実機が送信元アドレス・RSSI・応答メッセージ等を付加する場合は、`serial_lines()` でCSVとメタデータを取り出してから `Receiver.receive()` に渡すよう変更してください。無線モジュール設定コマンドは送信しません。実機接続は未検証です。

## ログとネット接続

- `logs/開始日時.jsonl` に正常・不正パケットと受信時刻を追記。起動ごとに新しいファイルになります。
- 入力元は `http` / `serial` / `demo` で区別。同一IDでも入力元別に集計します。総受信数にはDEMOも含まれます。
- ログは自動削除・ローテーションしません。長時間試験前にディスク容量を確認してください。
- 最新状態・回数はメモリ上にあり、再起動で初期化されます。過去ログの再生は未実装です。
- Leaflet 1.9.4はローカル同梱。背景地図OFFなら、インターネットなしでKMLと車両を描画します。
- 背景地図ONの場合のみOpenStreetMapのタイルを取得します。背景タイルのオフライン保存は含みません。
- サーバーはこのPCのみ（127.0.0.1）で利用する試験用です。
- 別KMLは `python server.py --kml "path/to/course.kml"`。Point/LineStringとMultiGeometry内の同要素に対応します。KMLの独自アイコン・スタイル・Polygonは再現しません。

## 検証

```console
python -m unittest -v
```

実KML解析、パケット不正値、HTTP入力、位置更新、SOS、入力元分離、ログ記録を確認します。

参考：[RallyStreamの画面構成](https://www.rallystream.net/jrc/2026/rd7/)、[Leaflet API](https://leafletjs.com/reference.html)。RallyStreamのコードや素材は使用していません。Leafletのライセンスは `static/vendor/LICENSE` に同梱しています。

## 画面から任意のKMLを読み込む

画面上部の「KMLを読み込む」で .kml ファイルを選択するとコースを置き換え、全体を表示します。Point / LineString / Polygon（穴を含む）とMultiGeometry内の同要素に対応します。20MB以下のUTF-8 KMLを使用してください。KMZ、NetworkLink、独自スタイル・アイコンは未対応です。
読み込みはブラウザ内で完結し、ファイルを外部に送信しません。この画面だけに適用され、再読み込みでサーバーの初期コースに戻ります。不正ファイルの場合は現在のコースを維持します。コース切替時に疑似走行を停止し、次回開始時は新しいコースを使用します。受信済み車両とログは維持されます。
